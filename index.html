Secure Implementation of Cryptographic Ciphers using Deep Neural Networks

Block ciphers implemented as neural networks, secured against key retrieval attacks.

  • Implemented PRESENT-80 and AES block ciphers entirely as PyTorch neural networks with fixed deterministic weights, encoding all cryptographic operations as custom NN layers.
  • Designed XORNet (ReLU-based), SBoxLayer (corner-function detection) and PermutationLayer (sparse matrix) as non-trainable PyTorch modules replicating exact cipher operations.
  • Hardened the implementations against key retrieval attacks, preserving cryptographic security properties within the neural network framework.
  • Verified correctness against all official test vectors with full pytest coverage across S-box, P-layer, key schedule and round key generation.
